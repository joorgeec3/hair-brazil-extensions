# Guia para editar o site pelo ChatGPT da cliente

**Projeto:** Hair Brazil Extensions
**GitHub:** https://github.com/joorgeec3/hair-brazil-extensions
**Site publicado:** https://hair-brazil-extensions-two.vercel.app/
**Branch:** main

## Primeiros passos
1. Entre no ChatGPT com a sua conta.
2. Conecte o GitHub em Configurações > Plugins ou pela opção de apps
   disponíveis. Autorize o acesso ao repositório quando solicitado.
3. Use o prompt abaixo para iniciar. O assistente deve ler este guia e
   `AGENTS.md` antes de alterar qualquer arquivo.
4. Para salvar diretamente no repositório da agência, é necessário aceitar
   um convite de colaboradora enviado pelo proprietário. O fato de o
   repositório ser público não concede autorização de escrita.
5. Se não houver permissão de edição, peça que o ChatGPT crie uma branch
   em um fork e um pull request para revisão pelo proprietário.
6. As mudanças só aparecem no site oficial quando uma publicação
   da Vercel for concluída. No plano Hobby, commits de outro autor podem
   não publicar automaticamente: peça ao proprietário para revisar e
   publicar, sem tentar contornar as permissões.

## Prompt para iniciar no ChatGPT da cliente

Sou responsável pelo conteúdo do site Hair Brazil Extensions e quero
editar o projeto existente pelo meu ChatGPT, sem criar um novo site.

Repositório: https://github.com/joorgeec3/hair-brazil-extensions
Branch principal: main
Site: https://hair-brazil-extensions-two.vercel.app/

Conecte e consulte meu GitHub. Leia `AGENTS.md` e
`GUIA_CLIENTE_CHATGPT.md` no repositório. Preserve todo o layout
atual, o catálogo, as fotos originais, os cursos, os preços confirmados
em USD, o carrinho, o WhatsApp, a navegação e os idiomas EN/PT/ES.

Quero que você faça as alterações que eu solicitar diretamente no
código existente, uma de cada vez, revisando o resultado no celular,
tablet e computador. Antes de mudar preços, confirme comigo o valor;
não invente valores pendentes. Nunca exponha credenciais ou ative
pagamentos sem minha autorização e a configuração da minha conta
Stripe.

Se tiver acesso de escrita, crie uma branch para minhas alterações e
abra um pull request. Se não tiver acesso, explique como aceitar o
convite de colaboradora ou como criar um fork e um pull request.
Confirme o que realmente foi alterado, mostre o link do PR e
não diga que publicou até verificar o status READY da Vercel.
